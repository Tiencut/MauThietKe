# Bridge Pattern - Java

## Cấu trúc

```text
src/
└── vn/
    └── edu/
        └── husc/
            └── tien_nguyenhuynhminhtien/
                ├── Demo.java
                ├── devices/
                │   ├── Device.java
                │   ├── Radio.java
                │   └── Tv.java
                └── remotes/
                    ├── Remote.java
                    ├── BasicRemote.java
                    └── AdvancedRemote.java
```

## Chạy bằng terminal

```bash
javac -encoding UTF-8 -d out src/vn/edu/husc/tien_nguyenhuynhminhtien/**/*.java src/vn/edu/husc/tien_nguyenhuynhminhtien/Demo.java
java -cp out vn.edu.husc.tien_nguyenhuynhminhtien.Demo
```
