PROJECT TEMPLATE DI THI MAU THIET KE

Ten project:
dp4-tien-nguyenHuynhMinhTien-template

Package:
vn.edu.husc.tien_nguyenhuynhminhtien

Cach dung khi vao thi:
1. Doi ten project neu de yeu cau.
2. Sua file dbscript_template.sql theo de.
3. Tao/sua entity theo bang trong database.
4. Sua DAO de SELECT dung bang.
5. Xem de ra mau nao thi code trong package tuong ung:
   - decorator
   - strategy
   - state
   - proxy
6. Xu ly logic trong service.
7. In ket qua trong main/Main.java.
8. Chup anh man hinh ket qua chay tu Eclipse, bo vao thu muc screenshot.

Quy tac nhanh:
- entity: class du lieu, gan voi bang.
- dao: chi doc/ghi database.
- service: xu ly nghiep vu va ap dung mau thiet ke.
- main: goi service/dao va in ket qua.
