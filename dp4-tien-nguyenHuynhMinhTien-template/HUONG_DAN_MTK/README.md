# Hướng dẫn Pattern Mẫu Thiết Kế

Bộ tài liệu này được viết theo kiểu:
- Nhìn nhanh để thi
- Copy skeleton code
- Dễ học thuộc và tìm file nhanh

## Cách dùng
1. Đọc `README.md` để biết pattern nào ở đâu.
2. Mở file pattern cần học trong `HUONG_DAN_PATTERN/`.
3. Nếu đề thi có pattern nào thì tìm đúng package tương ứng trong `src/vn/edu/husc/tien_nguyenhuynhminhtien/`.
4. Áp dụng luồng chung: `Main -> Service -> DAO -> Database`.

## Gợi ý học nhanh
- Học 3 nhóm chính: `tạo object`, `cấu trúc`, `hành vi`.
- Ưu tiên nạp: Decorator, Strategy, State, Proxy vì đề thi hay gặp và repo đã có sẵn package.
- Nhớ skeleton chung: `interface -> class cụ thể -> context/bộ bọc -> main`.
